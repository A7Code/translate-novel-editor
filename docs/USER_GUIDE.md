# 小說翻譯編輯器 — 使用手冊

本文件說明一般使用者如何安裝、啟用並操作「小說翻譯編輯器」這款 VSCode 套件。若你是要參與開發，請改閱讀 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 目前版本狀態

這個套件目前處於**開發初期（Phase 0）**：側邊欄介面與指令已經就位，但對應的業務邏輯（建立作品、比對編輯等）尚未實作，執行指令目前只會顯示「即將推出」的提示訊息。

也就是說，現在你可以先看到套件的介面長什麼樣子、未來會有哪些功能，但還不能真的拿它來翻譯小說。完整功能規劃請見下方〔未來功能預覽〕。

## 安裝方式

這個套件尚未上架 VSCode Marketplace，目前只能以下列方式之一安裝：

### 方式一：安裝 .vsix 封裝檔

若你拿到的是一個 `.vsix` 檔案：

1. 開啟 VSCode。
2. 按 `Ctrl+Shift+X` 開啟「擴充功能」面板。
3. 點選面板右上角的「...」選單 → 「從 VSIX 安裝...」。
4. 選擇該 `.vsix` 檔案即可完成安裝。

### 方式二：從原始碼以開發模式執行

若你拿到的是原始碼專案，可參考 [DEVELOPMENT.md](DEVELOPMENT.md) 中「啟動開發模式」的說明，按 `F5` 開啟一個已載入此套件的 VSCode 視窗來使用。

## 介面導覽

安裝並啟用後，VSCode 左側的 **Activity Bar（活動列）** 會出現「小說翻譯」圖示，點擊後會展開側邊欄，裡面有兩個區塊：

| 區塊 | 說明 |
| --- | --- |
| **作品總管** | 未來用來列出你管理的所有小說作品與章節。目前尚未建立任何作品時，會顯示提示文字與「建立新作品」的連結。 |
| **詞彙表** | 未來用來列出該作品專屬的名詞／片語翻譯對照表。目前為空白。 |

## 目前可用的指令

按 `Ctrl+Shift+P`（macOS 為 `Cmd+Shift+P`）開啟指令面板，輸入「小說翻譯」即可篩選出以下指令：

- **小說翻譯：建立新作品** — 目前會顯示「作品管理功能將於後續版本推出」的提示。
- **小說翻譯：開啟原文／譯文比對** — 目前會顯示「原文／譯文比對功能將於後續版本推出」的提示。

這兩個指令也可以直接從側邊欄「作品總管」View 的提示文字中點擊連結觸發。

## 未來功能預覽

依照目前的開發路線圖，之後會逐步推出：

1. **作品管理** — 新增作品、新增章節，並以純文字檔成對儲存原文與譯文。
2. **原文／譯文比對編輯** — 左右雙欄開啟同一章節的原文（唯讀）與譯文（可編輯），並同步捲動位置。
3. **詞彙表與自動完成** — 建立專屬於作品的名詞／片語對照表，輸入原文詞彙時可直接取得建議譯名。
4. **翻譯筆記** — 利用 VSCode 原生留言功能，針對特定段落留下翻譯筆記，並標記「待確認」、「已解決」等狀態。
5. **EPUB 匯入／匯出** — 直接匯入 EPUB 電子書作為原文章節來源，翻譯完成後再匯出回 EPUB 格式。

這些功能的詳細技術規劃屬於開發文件範疇，若你對實作細節感興趣，可參考專案中的 `PLAN.md`。

## 常見問題

**Q: 我執行了指令，但畫面上只顯示一句「即將推出」，是不是哪裡出錯了？**
A: 沒有出錯，這是目前版本的預期行為。套件仍在骨架階段，實際功能尚未實作。

**Q: 側邊欄的「作品總管」和「詞彙表」是空的，要怎麼加內容？**
A: 目前版本還無法新增內容，需等待後續版本釋出對應功能。
