# 小說翻譯編輯器 — 使用手冊

本文件說明一般使用者如何安裝、啟用並操作「小說翻譯編輯器」這款 VSCode 套件。若你是要參與開發，請改閱讀 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 目前版本狀態

這個套件目前處於**開發初期（Phase 4 — 翻譯筆記）**：已經可以建立作品、新增章節、匯入現有文字檔作為章節原文、開啟原文／譯文雙欄比對編輯、管理作品專屬的詞彙表與自動完成，並在原文／譯文上留下翻譯筆記、標記待確認或已解決；但 EPUB 匯入匯出尚未實作。

完整功能規劃請見下方〔未來功能預覽〕。

> 使用前請先在 VSCode 開啟一個**空的工作區資料夾**（即你要存放這部小說翻譯專案的資料夾），套件會在裡面建立 `.novel-translate/project.json` 設定檔，以及 `originals/`、`translations/` 兩個資料夾存放成對的原文／譯文純文字檔。

## 安裝方式

這個套件尚未上架 VSCode Marketplace，目前只能以下列方式之一安裝：

### 方式一：安裝 .vsix 封裝檔

若你拿到的是一個 `.vsix` 檔案：

1. 開啟 VSCode。
2. 按 `Ctrl+Shift+X` 開啟「擴充功能」面板。
3. 點選面板右上角的「...」選單 → 「從 VSIX 安裝...」。
4. 選擇該 `.vsix` 檔案即可完成安裝。

### 方式二：從原始碼以開發模式執行

若你拿到的是原始碼專案，可參考 [DEVELOPMENT.md](DEVELOPMENT.md) 中「啟動開發模式」的說明，按 `F5` 開啟一個已載入此套件的 VSCode 視窗來使用。

## 介面導覽

安裝並啟用後，VSCode 左側的 **Activity Bar（活動列）** 會出現「小說翻譯」圖示，點擊後會展開側邊欄，裡面有兩個區塊：

| 區塊 | 說明 |
| --- | --- |
| **作品總管** | 列出你管理的所有小說作品與章節。尚未建立任何作品時，會顯示提示文字與「建立新作品」的連結。 |
| **詞彙表** | 列出每個作品專屬的名詞／片語翻譯對照表，結構跟「作品總管」一樣是作品 → 詞條。尚未建立作品時會顯示提示文字。 |
| **設置** | 套件相關的設定項目，目前有「比對畫面同步捲動」與「詞彙表自動完成模式」兩個核取方塊，可直接勾選/取消勾選開關。 |

## 作品與章節管理

1. **建立新作品**：點擊「作品總管」View 右上角的 ➕ 圖示，或執行指令「小說翻譯：建立新作品」。依序輸入作品名稱、作者（可留空）、原文語言代碼（如 `en`）、譯文語言代碼（如 `zh-TW`，皆可留空）。
2. **新增章節**：在「作品總管」中對某個作品項目點擊滑鼠右鍵（或使用項目上的 📄 圖示），選擇「小說翻譯：新增章節」，輸入章節標題後會建立空白的原文／譯文純文字檔，並**直接進入下方的原文／譯文比對編輯**。
3. **匯入現有文字檔為章節**：在作品項目上按右鍵選擇「小說翻譯：匯入文字檔為章節」，挑選一個 `.txt`／`.md` 檔案作為該章節的原文內容；檔案會被複製進專案管理的 `originals/` 資料夾，完成後同樣會直接進入比對編輯。
4. **開啟章節比對**：點擊「作品總管」中的任一章節項目，就會直接開啟該章節的原文／譯文比對編輯（不需要先按右鍵），說明見下方。
5. **重新整理**：若 `.novel-translate/project.json` 被外部程式修改過，可點擊「作品總管」View 右上角的 🔄 圖示重新整理清單。

所有作品與章節的設定會存放在工作區資料夾中的 `.novel-translate/project.json`，原文與譯文則分別存放在 `originals/<作品ID>/` 與 `translations/<作品ID>/` 底下，以 `ch01.txt`、`ch02.txt`……依序命名。

## 原文／譯文比對編輯

點擊「作品總管」中的章節項目，即可開啟原文／譯文比對編輯（右鍵選單裡的「小說翻譯：開啟原文／譯文比對」效果相同；也可以直接從命令面板執行，會改成先用選單依序挑選作品與章節）：

- 左欄會開啟該章節的**原文**，並自動設為本次 VSCode 工作階段的唯讀狀態（不會更動檔案實際權限，重開 VSCode 後就會還原為可編輯）。
- 右欄會開啟對應的**譯文**，可直接編輯。
- 捲動其中一欄時，套件會自動把另一欄捲動到「目前最上面那一行」對應的同一行行號，讓兩欄的頂端行號盡可能一致，方便逐行對照。這是套件自己實作的同步機制，**不是**使用 VSCode 內建的「鎖定捲動」功能（內建功能用絕對像素差值同步，兩個檔案長度不同或編輯中捲動時容易把另一邊頂到檔案最底部，造成跳動）。
- 想暫時關掉同步捲動，有四種等效方式：執行指令「小說翻譯：切換原文／譯文同步捲動」、點擊比對視窗開著時出現在狀態列右側的「同步捲動：開／關」按鈕、到側邊欄「設置」View 取消勾選「比對畫面同步捲動」，或直接修改設定 `novelTranslate.compareScrollSync.enabled`。四個入口彼此同步，改任何一個其他地方都會跟著更新。

> 目前原文／譯文的對照是依照「行號相同」比對，尚未支援段落數不一致時的語意對齊——如果原文與譯文沒有維持相同的行數結構，對應到的內容可能不是同一段落。

## 詞彙表與自動完成

1. **新增詞條**：到側邊欄「詞彙表」View，對某個作品項目按右鍵（或點項目上的 📄 圖示）選擇「小說翻譯：新增詞條」，依序輸入原文詞彙、譯名、分類（可留空，例如人名／地名／專有名詞）、備註（可留空）。
2. **編輯詞條**：點擊「詞彙表」中的任一詞條項目，會用同一組輸入框、預先填好目前內容，修改後儲存即可。
3. **刪除詞條**：對詞條項目按右鍵選擇「小說翻譯：刪除詞條」，會先跳出確認對話框。
4. **重新整理**：View 右上角的 🔄 圖示。

建好詞彙表後，**在比對框的原文或譯文欄位打字時**，只要輸入到符合某個詞條的原文詞彙或譯名的任何一部分，自動完成清單就會同時列出該詞條的「原文」與「譯名」兩個選項供你選擇（提示文字會顯示對應的另一邊文字與分類，備註會顯示在建議的說明裡）。這是因為套件把原文與譯文檔案都標成了專屬的 `novel-translation` 語言模式，並：

- 關閉了該語言模式下 VSCode 內建「依文件既有單字聯想」的一般自動完成（避免跟詞彙表建議混在一起、互相干擾）；
- 只掛上詞彙表自己的建議來源。

> 原文欄位預設是「本次工作階段唯讀」，所以預設狀態下無法打字觸發自動完成；如果你需要在原文欄位輸入（例如校正原文），可先用 VSCode 的「切換目前分頁唯讀狀態」指令解除唯讀。

如果你想暫時切回一般自動完成（例如想用其他跟程式碼／語言相關的擴充功能），可以在原文或譯文分頁執行指令「小說翻譯：切換詞彙表自動完成模式」，它會把**目前這個分頁**的語言模式切到 `plaintext`；再執行一次就會切回 `novel-translation`。

如果你想直接關閉「開啟比對畫面時自動套用詞彙表自動完成模式」這個預設行為（而不是每次手動切換），到側邊欄「設置」View 取消勾選「詞彙表自動完成模式」即可——這會立即把**目前所有已開啟**的原文／譯文分頁切回 `plaintext`（一般自動完成），之後新開啟的比對畫面也會維持一般自動完成；再勾選回來則會立即把這些分頁切回 `novel-translation`，套用詞彙表建議。

> 目前自動完成的篩選是交給 VSCode 內建的模糊比對機制，沒有針對中文/日文等 CJK 文字斷詞做特別處理，篩選體驗可能不如預期精準。

## 翻譯筆記

在比對框的原文或譯文任一行，把滑鼠移到行號左側會出現 ➕ 圖示（這是 VSCode 內建的留言功能，不是側邊欄的獨立區塊）：

1. **新增筆記**：點擊行號旁的 ➕，在跳出的輸入框打字，按「送出」（或對應快速鍵）即可建立一則翻譯筆記，顯示在該行下方。
2. **回覆 / 補充**：已有筆記的那一行，點進去可以在同一個討論串繼續輸入文字並送出，變成多則留言。
3. **標記待確認／已解決**：點討論串右上角的「...」選單，選擇「切換已解決／待確認」。已解決的討論串會以 VSCode 原生的「已解決」樣式顯示（例如收合、變淡）。
4. **刪除整個討論串**：同樣在討論串的「...」選單選擇「刪除討論串」。注意這會整串刪除，目前不支援只刪除/編輯其中一則留言。
5. 所有留言也會集中顯示在 VSCode 的「留言」面板（命令面板輸入「Comments: Focus on Comments View」可開啟），方便跨章節瀏覽。

留言資料會存成工作區資料夾中的 `.novel-translate/comments/<作品ID>/<章節ID>.json`，原文、譯文側的留言都存在同一份檔案裡。

> 留言是依「行號」記錄位置的，如果之後在留言所在行的上方新增或刪除整段文字，留言可能會跟著往下/往上跑位、對不準原本想註記的段落——目前還沒有自動校正這個情況。

- **小說翻譯：新增章節**
- **小說翻譯：匯入文字檔為章節**
- **小說翻譯：重新整理作品清單**
- **小說翻譯：開啟原文／譯文比對**
- **小說翻譯：切換原文／譯文同步捲動**
- **小說翻譯：新增詞條**
- **小說翻譯：編輯詞條**
- **小說翻譯：刪除詞條**
- **小說翻譯：重新整理詞彙表**
- **小說翻譯：切換詞彙表自動完成模式**

## 常見問題

**Q: 開啟比對後，原文那一欄竟然可以編輯／沒有變成唯讀？**
A: 「唯讀」是透過 VSCode 的「本次工作階段唯讀」機制設定的，只在目前這次 VSCode 視窗生效；如果你重新整理或重開該檔案的分頁，可能需要再執行一次「開啟原文／譯文比對」來重新套用。

**Q: 詞彙表建好了，但輸入時沒有看到自動完成建議？**
A: 請確認目前分頁的語言模式是 `novel-translation`（透過比對框開啟的原文、譯文檔案都會自動套用；如果該分頁之前被切過語言模式，執行一次「小說翻譯：切換詞彙表自動完成模式」即可切回來），以及該作品的詞彙表確實有詞條。若是在原文欄位打字，也要確認該分頁已解除「本次工作階段唯讀」。另外部分輸入法的候選字視窗可能會跟自動完成清單互相擋住，可以先按 `Esc` 關閉輸入法候選視窗再看。

**Q: 行號左側沒有出現可以留言的 ➕ 圖示？**
A: 請確認這個檔案是透過「開啟原文／譯文比對」開啟的章節原文或譯文檔案——套件只在屬於某個章節的檔案上提供留言功能，其他檔案（例如你自己額外開的筆記檔）不會出現。

**Q: 「作品總管」裡看不到我建立的作品？**
A: 請確認你是在同一個工作區資料夾下操作——作品資料存放在該資料夾的 `.novel-translate/project.json`。若懷疑清單沒有同步，可點擊 View 右上角的 🔄「重新整理作品清單」。
