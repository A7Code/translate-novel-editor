# 小說翻譯編輯器 — 使用手冊

本文件說明一般使用者如何安裝、啟用並操作「小說翻譯編輯器」這款 VSCode 套件。若你是要參與開發，請改閱讀 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 目前版本狀態

這個套件目前處於**開發初期（Phase 1 — 作品管理）**：已經可以建立作品、新增章節、匯入現有文字檔作為章節原文；但原文／譯文比對編輯、詞彙表自動完成、翻譯筆記等功能尚未實作，相關指令目前只會顯示「即將推出」的提示訊息。

也就是說，現在你可以先用這個套件管理你的作品與章節清單，但還不能真的拿它來比對編輯翻譯內容。完整功能規劃請見下方〔未來功能預覽〕。

> 使用前請先在 VSCode 開啟一個**空的工作區資料夾**（即你要存放這部小說翻譯專案的資料夾），套件會在裡面建立 `.novel-translate/project.json` 設定檔，以及 `originals/`、`translations/` 兩個資料夾存放成對的原文／譯文純文字檔。

## 安裝方式

這個套件尚未上架 VSCode Marketplace，目前只能以下列方式之一安裝：

### 方式一：安裝 .vsix 封裝檔

若你拿到的是一個 `.vsix` 檔案：

1. 開啟 VSCode。
2. 按 `Ctrl+Shift+X` 開啟「擴充功能」面板。
3. 點選面板右上角的「...」選單 → 「從 VSIX 安裝...」。
4. 選擇該 `.vsix` 檔案即可完成安裝。

### 方式二：從原始碼以開發模式執行

若你拿到的是原始碼專案，可參考 [DEVELOPMENT.md](DEVELOPMENT.md) 中「啟動開發模式」的說明，按 `F5` 開啟一個已載入此套件的 VSCode 視窗來使用。

## 介面導覽

安裝並啟用後，VSCode 左側的 **Activity Bar（活動列）** 會出現「小說翻譯」圖示，點擊後會展開側邊欄，裡面有兩個區塊：

| 區塊 | 說明 |
| --- | --- |
| **作品總管** | 列出你管理的所有小說作品與章節。尚未建立任何作品時，會顯示提示文字與「建立新作品」的連結。 |
| **詞彙表** | 未來用來列出該作品專屬的名詞／片語翻譯對照表。目前為空白（Phase 3 才會實作）。 |

## 作品與章節管理

1. **建立新作品**：點擊「作品總管」View 右上角的 ➕ 圖示，或執行指令「小說翻譯：建立新作品」。依序輸入作品名稱、作者（可留空）、原文語言代碼（如 `en`）、譯文語言代碼（如 `zh-TW`，皆可留空）。
2. **新增章節**：在「作品總管」中對某個作品項目點擊滑鼠右鍵（或使用項目上的 📄 圖示），選擇「小說翻譯：新增章節」，輸入章節標題後會建立空白的原文／譯文純文字檔並自動開啟譯文檔案。
3. **匯入現有文字檔為章節**：在作品項目上按右鍵選擇「小說翻譯：匯入文字檔為章節」，挑選一個 `.txt`／`.md` 檔案作為該章節的原文內容；檔案會被複製進專案管理的 `originals/` 資料夾。
4. **開啟章節譯文**：點擊「作品總管」中的章節項目即可開啟對應的譯文純文字檔進行編輯。
5. **重新整理**：若 `.novel-translate/project.json` 被外部程式修改過，可點擊「作品總管」View 右上角的 🔄 圖示重新整理清單。

所有作品與章節的設定會存放在工作區資料夾中的 `.novel-translate/project.json`，原文與譯文則分別存放在 `originals/<作品ID>/` 與 `translations/<作品ID>/` 底下，以 `ch01.txt`、`ch02.txt`……依序命名。

## 目前可用的指令

按 `Ctrl+Shift+P`（macOS 為 `Cmd+Shift+P`）開啟指令面板，輸入「小說翻譯」即可篩選出以下指令：

- **小說翻譯：建立新作品**
- **小說翻譯：新增章節**
- **小說翻譯：匯入文字檔為章節**
- **小說翻譯：開啟章節譯文**
- **小說翻譯：重新整理作品清單**
- **小說翻譯：開啟原文／譯文比對** — 目前會顯示「即將推出」的提示（Phase 2 才會實作）。

## 未來功能預覽

依照目前的開發路線圖，之後會逐步推出：

1. **原文／譯文比對編輯** — 左右雙欄開啟同一章節的原文（唯讀）與譯文（可編輯），並同步捲動位置。
2. **詞彙表與自動完成** — 建立專屬於作品的名詞／片語對照表，輸入原文詞彙時可直接取得建議譯名。
3. **翻譯筆記** — 利用 VSCode 原生留言功能，針對特定段落留下翻譯筆記，並標記「待確認」、「已解決」等狀態。
4. **EPUB 匯入／匯出** — 直接匯入 EPUB 電子書作為原文章節來源，翻譯完成後再匯出回 EPUB 格式。

這些功能的詳細技術規劃屬於開發文件範疇，若你對實作細節感興趣，可參考專案中的 `PLAN.md`。

## 常見問題

**Q: 我執行了「開啟原文／譯文比對」，但畫面上只顯示一句「即將推出」，是不是哪裡出錯了？**
A: 沒有出錯，這是目前版本的預期行為。比對編輯功能屬於 Phase 2，尚未實作。

**Q: 側邊欄的「詞彙表」是空的，要怎麼加內容？**
A: 詞彙表管理屬於 Phase 3，目前版本還無法新增內容，需等待後續版本釋出對應功能。

**Q: 「作品總管」裡看不到我建立的作品？**
A: 請確認你是在同一個工作區資料夾下操作——作品資料存放在該資料夾的 `.novel-translate/project.json`。若懷疑清單沒有同步，可點擊 View 右上角的 🔄「重新整理作品清單」。
