# 小說翻譯編輯器（novel-translate-editor）

協助小說翻譯工作的 VSCode 套件，核心功能：

- 作品（小說）管理，支援從純文字檔或 EPUB 匯入
- 原文／譯文比對框（雙欄編輯器＋捲動同步）
- 作品專屬詞彙表（名詞／片語）管理，並掛入 IDE 自動完成
- 翻譯筆記（使用 VSCode 原生留言功能）
- EPUB 匯入／匯出：匯入既有 EPUB 自動拆出章節，翻譯完成後可回填原始排版匯出成新的 EPUB

目前狀態：Phase 0～5（基礎骨架、作品管理、比對框、詞彙表、翻譯筆記、EPUB 匯入／匯出）皆已完成，詳見 [PLAN.md](PLAN.md) 完整路線圖。
