# 小說翻譯編輯器（novel-translate-editor）

協助小說翻譯工作的 VSCode 套件。核心功能（開發中，見 [PLAN.md](PLAN.md) 完整路線圖）：

- 作品（小說）管理
- 作品專屬詞彙表（名詞／片語）管理，並掛入 IDE 自動完成
- 原文／譯文比對框（雙欄編輯器＋捲動同步）
- 翻譯筆記（使用 VSCode 原生留言功能）

目前狀態：**Phase 0 — 基礎套件骨架**。側邊欄與指令已就位，實際業務邏輯尚未實作。
